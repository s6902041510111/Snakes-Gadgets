# 🐍 บันไดงูไอที — IT Snake & Ladder Class

แอป Web สำหรับ **Active Learning** สอนคำศัพท์อุปกรณ์ไอที (CPU, RAM, SSD, GPU, Router, Switch, Monitor …)
ด้วยเกม **บันไดงู** ที่นักเรียนเข้าร่วมผ่าน Join Code + QR บนจอ Projector
อ่านคำใบ้ → แตะการ์ดของตัวเอง → เคลมคำตอบ → ครูตรวจ → เดินโทเคนบนกระดานรวม + สะสมคะแนน

ธีม **Cyber**: พื้น Slate Blue `#0f172a` / นีออน Cyan `#00f3ff` / นีออนม่วง `#9d4edd` / เขียวเรืองแสง `#00ff88`
พร้อม glassmorphism, glow, ไมโครอินเทอร์แอคชัน — ใช้ได้ทั้งบนจอ Projector และมือถือนักเรียน

## ✨ หน้าจอทั้งหมด

| ไฟล์ | หน้าจอ | ใช้โดย |
|---|---|---|
| `index.html` | หน้าหลักครู: เข้าสู่ระบบ, จัดการชุดกิจกรรม, ส่งออก/นำเข้าข้อมูล | ครู |
| `teacher.html?s=<sessionId>` | **Teacher Control**: สุ่มคำถาม, ตรวจคำเคลม, ปรับคะแนน, จบเกม | ครู |
| `projector.html?s=<sessionId>` | **Projector Display**: Join Code + QR, วงล้อ, กระดานรวม, อันดับสด | จอฉาย/ทีวี |
| `student.html?code=<รหัสห้อง>` | หน้านักเรียน: เข้าร่วม, การ์ดส่วนตัว, เคลมคำตอบ, อันดับ | นักเรียน (มือถือ/แท็บเล็ต) |

## 🚀 เริ่มใช้งาน

1. **เปิดด้วย double-click** (ไม่ต้องติดตั้งอะไร): เปิด `index.html`
   - ชื่อผู้ใช้เริ่มต้น: `Sathita` · รหัสผ่านเริ่มต้น: `1234`
   - เปลี่ยนได้ที่เมนู **⚙️ ตั้งค่า** (เก็บไว้ในเครื่อง, เข้ารหัสแบบ SHA-256+FNV)
2. (แนะนำ) เปิดผ่าน localhost เพื่อให้ API ทุกตัวทำงานครบ:
   ```powershell
   powershell -ExecutionPolicy Bypass -File serve.ps1
   # แล้วเปิด http://localhost:8099/
   ```
3. ครู: เลือกชุดกิจกรรม → **▶️ เปิดห้องเล่น** → ก๊อปปี้รหัสห้อง / เปิดจอ Projector ให้นักเรียนสแกน QR
4. นักเรียน: เปิด `student.html` → กรอกรหัสห้อง + ชื่อ → ได้การ์ด 4×4/3×3 ส่วนตัว (สุ่มคนละแบบ)
5. ครู: **▶️ เริ่มเล่น** → **🎲 สุ่มคำถามถัดไป** → วงล้อหมุนบนจอ (ยังไม่เฉลย)
   นักเรียนอ่านคำใบ้ → แตะการ์ด → **เคลม (ส่งคำตอบ)** → ครู **✔ ถูก / ✘ ผิด** (หรือ **⚡ ตัดสินอัตโนมัติ**)
   → โทเคนเดินบนกระดานรวมพร้อมบันได/งู → **🔔 เฉลย/จบรอบ** → รอบถัดไป
6. ครบรอบหรือครูกด **🏁 จบเกม** → อันดับสุดท้าย + การ์ดเฉลิมฉลอง + **⬇️ ส่งออก JSON/CSV**

## 🧮 ระบบคะแนน

| เงื่อนไข | คะแนน |
|---|---|
| ตอบถูก (ฐาน) | +100 |
| โบนัสความเร็ว | 0–50 (อ้างอิง 20 วิ: `(20s − เวลาตอบ)/20s × 50`) |
| โบนัส streak (ตอบถูกติดกัน) | 0–50 (ครั้งละ +10, เพดาน 50) |
| ตอบผิด | 0 (streak รีเซ็ต) |
| บิงโก (ต่อแถวครบ 3/4 ช่อง) | +150 (ตรวจฝั่งนักเรียนจาก**การ์ดของตัวเอง**) |
| เดินโทเคน | +1 ช่องต่อคำตอบถูก → บันได 🪜 พุ่งขึ้น / งู 🐍 ตกกลับ / ช่องสุดท้าย = ผู้ชนะ |

รูปแบบชัยชนะของชุดกิจกรรม: พร้อมใช้ `row / col / diag` (กำหนดได้ตอนสร้างชุด)

## 💾 โมเดลข้อมูล (พร้อมต่อยอด Vercel)

ทุกคีย์เก็บเป็น **JSON envelope** เดียวกัน:
```json
{ "schema": 1, "rev": 5, "updatedAt": "2026-09-28T15:52:34.942Z", "payload": { "items": [...] } }
```
คีย์ใน `LocalStorage` (ชื่อขึ้นต้น `itsc:v1:`):

- `auth` — ข้อมูลล็อกอินครู (salt + hash)
- `sets` — ชุดกิจกรรม `{ name, grade, gridSize, rounds, trackLength, winPatterns, snakesLadders, items[] }`
- `sessions` — ห้องเล่นทั้งหมด (สถานะ รอบ ผู้เล่น คำเคลม ผลลัพธ์ log)
- `prefs` — ค่ากำหนด (เสียง, ครูคนล่าสุด)
- `identity` — ตัวนักเรียนเครื่องนี้ (local เท่านั้น, ไม่ sync)

ทุกห้องเก็บ `setSnapshot`(สำเนาชุดกิจกรรม) ไว้ในตัวเอง → ลบ/แก้ชุดทีหลังก็ไม่กระทบห้องที่เปิดอยู่
`index.html` มีปุ่ม **ส่งออกข้อมูลทั้งหมด / นำเข้า** รองรับการสำรองและย้ายเครื่อง
และโครงสร้าง `ITS.store` ออกแบบให้สลับ backend จาก LocalStorage เป็น **Vercel KV/Blob** ได้โดยตรง

## 🔄 การซิงค์ระหว่างหน้าจอ

- **LocalStorage + BroadcastChannel + polling (600 ms)** — หลายหน้าต่างบนเครื่องเดียวกัน sync สด
- **หมายเหตุ (ข้อจำกัดที่ตั้งใจ):** โหมดทำงานในเครื่องเดียวหลายหน้าต่าง
  - ถ้าเปิดนักเรียน **2 คนในเครื่องเดียว** ระบบจะจำนักเรียนเป็นคนเดียว (เพราะใช้ key `identity` ร่วมกัน) —
    ในห้องจริงนักเรียนแต่ละคนใช้เครื่อง/เบราว์เซอร์ของตัวเอง ⇒ ไม่มีปัญหา
  - การเล่น **ข้ามอุปกรณ์จริง** (ครูจอใหญ่ + นักเรียนมือถือ) ยังเป็นงานต่อยอด:
    เพิ่ม adapter relay ผ่าน Vercel KV/Blob (ช่อง `ITS.remote` พร้อมแล้ว) – ดูส่วน Deploy

## ☁️ Deploy ไป Vercel (ใช้ได้บนอินเทอร์เน็ต)

โฟลเดอร์นี้เป็น **static** (HTML + vanilla JS, ไม่ต้อง build) → ขึ้น Vercel ได้ทันที
**หมายเหตุ:** ต้องมี Node.js เฉพาะ**ขั้นตอน deploy** เท่านั้น — ตัวแอปเวลานำไปใช้จริง
ยังเปิดแบบ double-click ได้ตามเดิม ไม่ต้องติดตั้ง Node

### วิธีที่ 1 — ใช้สคริปต์ `deploy.ps1` (แนะนำ)

1. ติดตั้ง Node.js LTS ครั้งเดียว: เปิด https://nodejs.org → ดาวน์โหลด LTS → Next > Next
2. เปิด PowerShell ในโฟลเดอร์นี้ แล้วรัน:
   ```powershell
   powershell -ExecutionPolicy Bypass -File deploy.ps1
   ```
3. ครั้งแรกเบราว์เซอร์จะเปิดให้ **ล็อกอิน Vercel** (สมัครฟรีได้ทันที: GitHub/Google/email)
4. เสร็จแล้วสคริปต์แสดง URL เช่น `https://it-snake-ladder-class.vercel.app/`
   เปิด URL นั้นใช้งานบนมือถือ/เครื่องอื่นได้เลย (โหลดหน้าเดียวกันผ่านอินเทอร์เน็ต)

ตัวเลือก `-Preview` ใช้ทดสอบก่อนขึ้นจริงได้ (ยังไม่ผลักขึ้น production)

### วิธีที่ 2 — ใช้ Vercel CLI เอง (ต้องมี Node.js)

```bash
npm i -g vercel   # เครื่องที่ยังไม่มี
vercel            # ครั้งแรก: ตั้งชื่อโปรเจกต์ + ล็อกอิน
vercel --prod     # ขึ้น production ทุกครั้งหลังแก้ไฟล์
```

### วิธีที่ 3 — ผ่าน GitHub (ขั้นสูง)

```bash
git init && git add . && git commit -m "init"
# push ไป GitHub → เข้า vercel.com → New Project → Import repo
# ข้อดี: push ใหม่ทุกครั้ง deploy อัตโนมัติ
```

> ⚠️ **ข้อจำกัดที่ยังมี:** ขึ้น Vercel แล้ว ทุกคนเปิด URL เดียวกันได้ แต่ข้อมูลห้อง/คะแนน
> ยังแยกตามเครื่อง (localStorage ต่อคน) — เหมาะสาธิตหลายแท็บ หรือนักเรียนตอบในเครื่องครู
> การเล่นข้ามเครื่องจริง (นักเรียนมือถือ + จอครูพร้อมกัน) ต้องเพิ่ม relay `ITS.remote`
> ผ่าน Vercel KV/Blob (โครงสร้างพร้อมแล้ว เป็นงานต่อยอด)
